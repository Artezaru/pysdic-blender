pysdic_blender.BlenderExperiment#

class BlenderExperiment(*, background_color=(1.0, 1.0, 1.0), background_strength=0.0)[source]#

Bases: object

A Blender scene of cameras, meshes and spot lights, rendered with Cycles.

The objects of pysdic are converted when they are added (see BlenderCamera, BlenderMesh, BlenderMaterialBSDF, BlenderSpotLight). The scene is rendered from one camera at a time with render(), which returns the image as an array.

For a sequence of frames, update the scene between the renders, e.g. the vertices of a mesh displaced by the displacement of each frame (update_mesh()).

Important

Requires bpy (Blender as a Python module), imported at the creation of the first experiment. Each release of bpy supports exactly one version of Python.

Blender has one global state: creating an experiment clears all the data of Blender (factory settings, empty scene), and only the last created experiment can be used (the previous ones raise an error).

Colors. The render is saved in OpenEXR (32-bit float, scene-linear values, without the tone curve of the view transform) and returned as a linear intensity: the mean of the RGB channels. Map it to gray levels and quantize it in pysdic (e.g. a gain, then pysdic.add_gaussian_noise() and pysdic.quantize_image()), as for pysdic.generate_synthetic_image().

Parameters:

  • background_color (ArrayLike, optional (default: (1.0, 1.0, 1.0))) – The RGB color of the world (ambient light).

  • background_strength (Real, optional (default: 0.0)) – The strength of the ambient light (0: only the spot lights).

Examples

from pysdic_blender import BlenderCamera, BlenderExperiment, BlenderMesh, BlenderSpotLight, get_matte_paint_material

experiment = BlenderExperiment(background_strength=0.2)
experiment.add_camera("left", BlenderCamera(left_camera))
experiment.add_camera("right", BlenderCamera(right_camera))
experiment.add_spotlight("spot", BlenderSpotLight.looking_at([0.0, 0.0, 600.0], [0.0, 0.0, 0.0], energy=5e5))
experiment.add_mesh("specimen", BlenderMesh(mesh, texture=speckle), material=get_matte_paint_material())

images = {}
for frame, displacement in enumerate(displacements):
    experiment.update_mesh("specimen", BlenderMesh(mesh, displacement=displacement))
    images[frame] = [experiment.render(name, n_samples=256) for name in ("left", "right")]

Add a mesh (see BlenderMesh) to the scene with a material (Principled BSDF, see BlenderMaterialBSDF; by default the default material of Blender).

render(camera, *, n_samples=128, filter_width=1.5, seed=0, device='CPU', gpu_backend='CUDA')[source]#

Render the scene from a camera with Cycles.

Parameters:

  • camera (str) – The name of the camera.

  • n_samples (Integral, optional (default: 128)) – The number of samples per pixel (the noise of Cycles decreases as \(1 / \sqrt{n}\)). No denoising is applied.

  • filter_width (Real, optional (default: 1.5)) – The width in pixels of the pixel filter of Cycles (Blackman-Harris): the blur of the render.

  • seed (Integral, optional (default: 0)) – The seed of the sampling of Cycles (reproducible renders).

  • device (str, optional (default: "CPU")) – "CPU" or "GPU".

  • gpu_backend (str, optional (default: "CUDA")) – The backend of the GPU devices: "CUDA", "OPTIX", "HIP", "METAL" or "ONEAPI" (only with device="GPU").

Returns:

The linear intensity \((H, W)\) (float64), mean of the RGB channels, with the rows of the image from top to bottom (pysdic convention).

Return type:

numpy.ndarray
