Welcome to pysdic-blender’s documentation!#

Description of the package#

Rendering of synthetic images with Blender (lighting, shading, materials) from the objects of pysdic (cameras and meshes).

pysdic.generate_synthetic_image() renders the exact gray levels of a textured mesh, without lighting. pysdic-blender drives Blender (Cycles renderer) to render the same scene with lighting, shading and the reflections of a material.

Important

pysdic-blender is a separate package because bpy (Blender as a Python module) exists for only one version of Python per Blender release: pysdic-blender requires Python 3.13 (bpy 5.1), while pysdic supports Python 3.11 and later.
